🎤 SkillSync AI – Mock Interview Platform

SkillSync AI is an AI-powered mock interview platform that helps students and professionals prepare for job interviews by simulating real interview scenarios. The system analyzes resumes, generates interview questions, evaluates voice confidence, and provides a performance report.

The goal of this project is to help users practice interviews, improve communication skills, and build confidence before attending real job interviews.
🚀 Features

📄 Resume Upload & Analysis
Upload your resume and receive a basic evaluation score.

🤖 AI Interview Question Generator
The system generates random interview questions from a question bank.

🎤 Voice Confidence Analyzer
Detects microphone input and analyzes speaking confidence during the interview.

📊 Performance Evaluation
Provides scores for:

Resume quality

Voice confidence

Overall interview performance

📥 Interview Report Download
Users can download a report of their interview results.

👤 User Login System
Simple login modal to personalize the session.

📬 Contact Form
Allows users to send feedback or inquiries.

🧠 How It Works

User logs into the platform.

User uploads their resume.

The backend analyzes the resume and assigns a score.

The system generates interview questions.

The microphone detects voice activity during responses.

After completing the interview, the system calculates scores.

A final performance report is generated and can be downloaded.
